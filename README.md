
# Feed to2en1.app -> Meta Catalog

Micro-servicio que genera feed CSV para Facebook Catalog escaneando https://www.to2en1.app/shop

Deploy en Vercel en 1 clic:

1. Sube esta carpeta a GitHub
2. Ve a vercel.com -> Import Project -> Selecciona el repo
3. Deploy -> te da URL: https://tu-proyecto.vercel.app/api/feed

Esa URL es tu feed para Meta:
Commerce Manager > Catalogo > Origen de datos > Feed > Pegar URL

Actualiza solo cada 6 horas.
